# AssetLens

AssetLens 是一个本地运行的个人资产与 FIRE 追踪应用。它基于 Vite、React 和 TypeScript 构建，用来导入、整理和复盘不同时间点的全量资产快照。

这个项目关注的是“某个时间点有多少资产、分布在哪里、变化趋势如何”，不是收入支出流水账。

## 功能概览

- **仪表盘**：查看净资产、负债、分类占比、账户分布和资产变化趋势。
- **明细表**：按快照日期查看各账户金额，并支持直接维护数据。
- **导入数据**：支持上传 `.xlsx` 文件或粘贴表格文本，导入前可检查字段映射和数据质量。
- **策略配置**：维护账户分类、是否计入统计等分析口径。
- **复盘报告**：基于资产快照生成阶段性复盘信息。
- **FIRE**：根据月支出、安全提取率、应急备用金和预期年化收益率估算 FIRE 进度。

信用卡等欠款记为 **负债** 账户：金额填欠款正数，净资产 = 总资产 − 负债。每期还可记录 **外界收入**（工资等非理财流入），用来把主动攒钱和市场涨跌分开看。某一期没有填写外界收入时，会沿用更早最近一次有记录的金额，并同时标明来源日期和距今天数。

## 数据模型

AssetLens 的核心数据是资产快照：每一行代表一个日期，每个账户列代表该日期的账户金额。

示例：

```text
时间        基金账户A  占比    现金账户A  占比    合计
2026-05-01  59000       34.3%   10000       5.8%   69000
```

导入时需要注意：

- 第一行必须是表头，第一列建议命名为 `时间`。
- 每个账户只需要导入金额列；`占比` 列会默认忽略，应用会按金额重新计算占比。
- `合计` 列可选；如果它不是各账户金额加总，应在字段映射里改成“忽略”。Excel 合计按账户金额加总对照（负债按欠款正数），网页净资产会再扣掉负债。
- `收入` 列会导入为该期外界收入；`备注` 会导入；`时长`、`变动`、`日均`、`结余` 默认忽略。
- 信用卡、花呗、白条等账户会识别为 `负债`，金额填欠款正数。
- 金额支持 `1,234.56`、`￥1,234.56`、`$12,574.53`、空值和 `-`。
- 遇到重复日期时，可以选择覆盖、保留新记录或跳过。

数据会保存在本地浏览器中，不依赖后端服务。

## FIRE 说明

FIRE 页是独立功能页，核心输入包括：

- 月支出
- 安全提取率
- 应急备用金月数
- 预期年化收益率

其中“历史速度估算”只基于资产快照变化，包括最近一次更新、近一年和历史以来；它不受预期年化收益率影响。“按预期年化收益率”才会使用预期收益率进行估算。

## 项目结构

```text
src/
  components/  页面组件与功能区组件
  lib/         数据计算、导入、存储和格式化逻辑
  main.tsx     应用入口
  App.tsx      顶层应用结构
```

## 开发约定

- 修改代码前先理解现有结构与需求。
- 优先保持实现简单、清晰、可维护。
- 完成前运行：

```bash
npm test && npm run build
```

- 涉及 UI 或图表改动时，需要启动浏览器实际检查，不能只依赖测试或构建。
- 本项目只应保留一个 dev server，默认使用 `http://127.0.0.1:5173/`。
